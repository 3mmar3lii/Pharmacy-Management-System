4.1 LOGIN PAGE
--------------
  Layout: Centered glassmorphism card on gradient background
          No sidebar, no navbar. Split layout optional (left=illustration)

  Components:
    Logo             Image, centered at top of card
    Title            "Pharmacy Management System"
    Subtitle         "Sign in to your account"
    Email input      Label: "Email", placeholder: "Enter your email"
                     Icon: envelope on left
    Password input   Label: "Password", with show/hide eye toggle
                     Icon: lock on left
    Remember me      Checkbox (optional)
    Login button     Full width, primary gradient bg, "Sign In"
                     Loading: spinner replaces text
    Error alert      Red banner with icon, slides in from top

  Validations:
    Email: required, valid format. Inline error below field.
    Password: required, min 6 chars. Inline error below field.

  Advanced:
    - Subtle background animation (floating shapes or particles)
    - Input focus: glow border animation (box-shadow with primary color)
    - Button: gradient shift on hover


4.2 DASHBOARD PAGE
------------------
  ROW 1 - Summary Cards (4 cards, equal width)
    Card 1: "Today's Sales"      Icon: dollar     Value: "EGP 12,500"   Blue gradient
    Card 2: "Total Medicines"    Icon: pill       Value: "1,247"        Green gradient
    Card 3: "Low Stock Items"    Icon: warning    Value: "23"           Amber gradient
    Card 4: "Expiring Soon"      Icon: clock      Value: "8"            Red gradient

    Advanced per card:
      - Glassmorphism background
      - Count-up number animation on load
      - Subtle hover: lift + shadow increase
      - Small sparkline/trend line below value
      - Percentage change indicator (+12% or -5% vs yesterday)

  ROW 2 - Charts (2 columns, 60%/40%)
    Left:  Sales Trend Chart (line/area chart, gradient fill under line)
           Last 30 days. Toggle: Daily / Weekly / Monthly
           Tooltip on hover showing exact value
    Right: Top Selling Medicines (horizontal bar chart)
           Top 5, gradient bars, animated load

  ROW 3 - Tables (2 columns, 50%/50%)
    Left:  Recent Sales
           Columns: Invoice#, Customer, Amount, Time
           Last 10 sales. Click row -> Sale details.
           Hover: row highlight animation
    Right: Alerts Panel
           Combined: Low stock (amber icon) + Expiring (red icon)
           Medicine name + status badge
           Click -> Medicine details
           Scrollable max-height with fade


4.3 MEDICINE LIST PAGE
----------------------
  Top Bar:
    Page title: "Medicines" (H1) + Breadcrumb
    "+ Add Medicine" button (primary, top right, icon + text)

  Filters Row (collapsible on mobile):
    Search        Text input with search icon, debounced (300ms)

    - Sortable columns (click header, arrow indicator)
    - Row hover animation (subtle bg + slight left border)
    - Zebra striping (alternating row colors)

4.7 SALES / POS PAGE (Most Complex)
-------------------------------------
  Layout: 2-panel layout (side by side)

  LEFT PANEL (60%):
    Search Bar:     Large, prominent. Auto-complete dropdown as you type.
                    Search by name or barcode. Shows: Name, Stock, Price.
                    Keyboard shortcut: F2 to focus search
    Search Results: Clickable cards/list. Click -> add to cart qty=1.
                    Each result shows: name, available stock, price
                    Out-of-stock items grayed out
    Customer Select: Dropdown below search: "Walk-in" (default) or search customer
    Quick Actions:   Recent/frequent medicines as pill buttons

  RIGHT PANEL (40%) - Cart / Invoice:
    Cart Items Table:
      Medicine name
      Qty (editable: - and + buttons, or type number)
      Unit Price
      Item Discount (input: amount or %)
      Line Total
      Remove (X button with confirmation)

    Calculations:
      Subtotal:        Sum of line totals
      Overall Discount: Input (fixed or % toggle)
      Tax (14%):       Auto from settings
      ==================
      GRAND TOTAL:     Large, bold, prominent

    Payment Section:
      Payment Method:  Segmented buttons: Cash | Card | Insurance
      Paid Amount:     Number input (for cash)
      Change:          Auto-calculated (paid - total)

    "Complete Sale" button: Full width, large, primary gradient
                           Disabled if cart empty
                           Keyboard shortcut: F5

  After Sale Success:
    Modal: Success animation (checkmark), Invoice number
    Buttons: "Print Receipt", "New Sale", "View Invoice"

  Advanced POS Features:
    - Barcode scanner support (auto-focus search)
    - Keyboard shortcuts displayed as tooltips
    - Cart item reorder via drag
    - Real-time stock validation (warn if qty > available)
    - Sound feedback on item add (subtle click)
    - Running total always visible even when scrolling

7. DATA FLOW PATTERN
================================================================================

  Component --> calls --> Feature Service --> HTTP --> Backend API
  Backend API --> JSON --> Feature Service --> Observable --> Component --> Template

  Auth Interceptor: Attaches JWT token to every outgoing request
  Error Interceptor: Catches 401/403/500, shows toast notification globally

  Key Patterns:
    - Each feature module has its own service (MedicineService, SaleService, etc.)
    - Services use HttpClient with typed TypeScript interfaces
    - Components subscribe to observables
    - Reactive forms with FormBuilder for all forms
    - OnPush change detection for performance

8. KEY USER FLOWS (FOR FIGMA PROTOTYPING)
================================================================================

  FLOW 1: Login -> Dashboard
    Login Page -> Enter credentials -> Click Sign In -> Dashboard loads

  FLOW 2: Add Medicine
    Sidebar: Medicines -> List -> "+ Add" -> Fill form -> Save
    -> Redirect to list + success toast

  FLOW 3: Make a Sale (POS)
    Sidebar: Sales -> POS -> Search medicine -> Add to cart
    -> Adjust qty -> Select customer -> Choose payment
    -> Enter paid amount -> "Complete Sale"
    -> Success modal -> Print receipt

  FLOW 4: Purchase Order
    Sidebar: Purchases -> List -> "+ New PO" -> Select supplier
    -> Add medicines + qty -> Submit -> PO created (Pending)
    -> Admin approves -> Mark Ordered -> Goods arrive
    -> Mark Received -> Stock auto-updated
